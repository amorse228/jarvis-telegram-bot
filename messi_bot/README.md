# 🐶 Месси — собачка в Телеграме

Бот-питомец: французский бульдог Месси (девочка) пишет своей семье. Отвечает через Claude, помнит, о чём ей рассказывали, и сама пишет первой, когда соскучилась.

## Что умеет

- **Мозг** — отвечает как настоящая собака, с характером, по-русски, коротко и тепло.
- **Память**
  - помнит последние 40 сообщений переписки с каждым;
  - сама записывает важные факты в долгую память (дни рождения, планы, что кто любит);
  - **секреты**: если папа говорит «это сюрприз, маме не говори», Месси сохранит это как секрет, и мама его не увидит;
  - `/memory` — посмотреть, что она помнит, `/forget 12` — удалить факт.
- **Передаёт сообщения**: «Месси, передай маме, что я её люблю» — и она напишет маме сама.
- **Тамагочи**: кнопки 🍖 Покормить / 🦮 Гулять / 🎾 Играть / 🤗 Погладить. Сытость, энергия и настроение со временем падают, и это видно по её сообщениям.
- **Пишет первой**: с 9:00 до 23:00, если вы не общались 3+ часа, утром здоровается. Не больше 3 раз в день.
- **Видит фото**: пришли ей фото — она его прокомментирует.
- Отвечает только двум id из `.env`, всех остальных вежливо отшивает.

## Запуск

Нужен Python 3.10+.

```bash
cd messi_bot
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env              # Windows: copy .env.example .env
```

Заполни в `.env`:
- `BOT_TOKEN` — токен от @BotFather;
- `ANTHROPIC_API_KEY` — ключ с https://platform.claude.com/ (API Keys, нужен баланс).

```bash
python main.py
```

После этого **вы оба** должны открыть бота и нажать /start, иначе Месси не сможет писать вам первой.

## Чтобы работало круглосуточно

Бот работает, пока запущен `main.py`. Чтобы Месси писала и тогда, когда компьютер выключен, запусти его на сервере (любой дешёвый VPS). Пример для Linux с systemd — `/etc/systemd/system/messi.service`:

```ini
[Unit]
Description=Messi bot
After=network.target

[Service]
WorkingDirectory=/home/USER/jarvis-telegram-bot/messi_bot
ExecStart=/home/USER/jarvis-telegram-bot/messi_bot/venv/bin/python main.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now messi
```

Вся память лежит в файле `messi.db`: не удаляй его, иначе Месси всё забудет.

## Настройка характера

Характер описан в `brain.py`, в переменной `PERSONA`. Туда можно дописать настоящие привычки Месси: как она храпит, что ворует со стола, как зовут её игрушку. А можно ничего не править и просто рассказать ей это в чате: она запомнит.
